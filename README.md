
# Golf Analytics

## Project Description
Golf Analytics is a Python-based application designed to analyze golf performance and predict shot distances using machine learning.

The project uses synthetically generated golf data and provides data visualization, statistical analysis, and predictive modeling.

## Features
- Synthetic golf dataset generation
- Golf performance analysis
- Data visualization
- Shot distance prediction
- Comparison of actual and predicted distances
- Model error analysis
- Feature importance analysis
- Wind speed and distance analysis

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Tkinter

## Installation

1. Clone or download the project.
2. Install the required libraries:

   pip install -r requirements.txt

3. Run the application:

   python app.py

## Dataset
The project uses synthetically generated data. No external datasets or paid APIs are required.
